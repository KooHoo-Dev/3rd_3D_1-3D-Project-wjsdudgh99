# 3D 게임 기획서: You're Right

## 1. 게임 개요

### 1.1 한 줄 요약
> 기존의 '틀린 그림 찾기' 룰을 뒤집어, 두 개의 3D 디오라마(Diorama) 모델을 
> 오빗 뷰(Orbit View)로 이리저리 돌려보며 '완벽하게 똑같은(맞는) 부분'을 찾아내는 관찰형 3D 퍼즐 게임.

### 1.2 목표 플레이어 경험
*   **색다른 퍼즐의 신선함:** 수많은 차이점 속에서 '공통점'을 찾아내는 역발상의 재미.
*   **여유로운 관찰과 힐링:** 체력이나 제한 시간, 게임 오버의 압박 없이 느긋하게 디오라마의 아름다움을 감상하며 문제를 푸는 경험.
*   **기록 단축의 성취감:** 스톱워치를 통해 자신의 클리어 시간을 측정하고, 전체 스테이지 완주 시간을 단축하기 위해 재도전하는 재미.

### 1.3 프로젝트의 핵심
*   **카메라 조작과 시각적 탐색:** 마우스 휠과 WASD(또는 드래그)를 통해 3D 공간을 확대/축소/회전하며 사각지대에 숨겨진 디테일을 찾는 것이 핵심 메커니즘.
*   **타임 어택 룰:** 첫 스테이지 진입과 동시에 스톱워치가 작동하며, 지정된 개수의 정답을 모두 찾으면 즉시 시간이 기록되고 다음 스테이지로 넘어가는 심플한 게임 루프.

## 2. 오브젝트 명세 및 3D 물리

### 2.1 카메라 및 플레이어 입력 (Player / Camera)
*   **카메라 뷰:** 화면을 둘로 나눈 분할 화면(Split Screen). 카메라 2대가 각자의 중심점을 축으로 도는 오빗 뷰(Orbit View)이며, 항상 같은 각도·거리를 유지해 두 대상을 같은 시점에서 나란히 비교할 수 있음.
    *   **월드 1:** 좌/우 분할. 각 화면 가운데에 섬이 하나씩 보임.
    *   **월드 2:** 위/아래(가로) 분할. 나머지는 월드 1과 같음.
    *   **월드 3:** 좌/우 분할이지만, 물체 하나가 화면 정중앙에서 분할선에 반으로 갈려 보임. 왼쪽 반은 버전 A, 오른쪽 반은 버전 B를 비춤(두 카메라가 화면 전체 기준으로 그리고 각자 반쪽만 보여 줌).
*   **입력 로직:**
    *   **회전:** WASD 키 (또는 마우스 우클릭 드래그)로 두 카메라를 동시에 같은 각도로 회전.
    *   **줌:** 마우스 휠 스크롤로 두 화면을 동시에 확대 및 축소.
    *   **상호작용:** 마우스 좌클릭 시 커서가 있는 쪽 화면의 카메라에서 Raycast를 발사하여 오브젝트 클릭 판정.

### 2.2 디오라마 환경 (Environment)
*   **구성:** 비슷한 테마의 작은 3D 디오라마 섬 2개를 서로 멀리 떨어뜨려 배치하고(예: x -100 / x 100), 왼쪽 화면에 섬 A, 오른쪽 화면에 섬 B를 비춤. 카메라 Far Clip을 짧게 두어 반대편 섬은 보이지 않게 함.
*   **월드 3 구성:** 섬 대신 물체 하나를 두 버전으로 만들어 같은 방식으로 떨어뜨려 배치함(예: 평범한 지구 / 운석이 떨어진 멸망 직전의 지구).
*   **물리:** 지형이나 배경 에셋에는 충돌 판정(Collider)을 주지 않거나, Raycast에 잡히지 않도록 Layer를 분리하여 클릭 방해 요소를 제거.

### 2.3 정답 오브젝트 (Target Objects)
*   **구성:** 두 디오라마에 '완전히 똑같은 형태와 색상'으로 배치된 쌍둥이 오브젝트.
*   **물리:** 정답 처리가 필요한 오브젝트에는 반드시 Mesh Collider 또는 Box/Sphere Collider를 부착하여 마우스 Raycast가 인식할 수 있도록 처리.

## 3. 게임 시스템

### 3.1 스테이지 구조
*   **스테이지 개수:** 총 10개 (튜토리얼 1개 + 월드 3개 × 3스테이지).
    *   튜토리얼 / 1-1, 1-2, 1-3 / 2-1, 2-2, 2-3 / 3-1, 3-2, 3-3
    *   **월드 1을 먼저 완성**하고, 시간이 허락하면 월드 2, 3을 추가함. 월드 1까지만으로도 완성된 게임으로 제출할 수 있게 만듦.
*   **문제 개수:** 스테이지별로 찾아야 할 정답 개수는 3~5개로 구성. 튜토리얼은 3개.
*   **튜토리얼:** 시작 전에 안내 패널(규칙 → 조작법 → 시작하기, 3페이지)이 뜨고, 시작하기를 누르면 스톱워치가 돌기 시작함. 튜토리얼 시간은 HUD에만 보이고 결과 기록과 Total Time에는 넣지 않음.
*   **고유 환경 연출:** 맵마다 어울리는 연출을 골라 넣음. **튜토리얼과 1-1은 연출 없이 기본 조명만** 사용하고(기본을 먼저 완성한 뒤 커스텀), 1-2부터 연출을 넣음.
    *   후보: 형광등 깜빡임(10초 간격, 1초 이내), Directional Light가 회전하는 일출·일몰, 어두운 배경의 네온사인(Emission).
    *   월드 3에서 Directional Light를 카메라 자식으로 두면 어느 방향에서 봐도 앞면이 밝고, 고정해 두면 뒤쪽이 어두워짐(낮·밤 연출). 맵마다 고름.

### 3.2 게임 클리어 조건
*   **스테이지 클리어:** 한 스테이지 내에 존재하는 모든 정답 오브젝트(예: 5개)를 클릭하여 찾아냄.
*   **게임 클리어:** 마지막 스테이지의 모든 정답을 찾아냄.

### 3.3 씬 간 데이터 전달 (GameManager 활용)
*   **`Play Scene` ➔ `Result Scene`:**
    *   전달 데이터: `각 스테이지별 소요 시간(float)`, `총 누적 소요 시간(float)`.
    *   방식: `DontDestroyOnLoad`가 적용된 GameManager 스크립트나 `PlayerPrefs`를 사용하여 데이터를 저장하고 결과 창에서 호출.

## 4. 씬 구성 및 UI

### 4.1 메인 화면 (Menu Scene)
*   **UI 요소:** 아기자기하고 편안한 분위기의 게임 타이틀 텍스트, Start 버튼, Exit 버튼.
*   **기능:** Start 누를 시 첫 번째 스테이지 로드, Exit 누를 시 게임 종료.

### 4.2 게임 플레이 화면 (Play Scene)
*   **HUD (상단 고정 UI):**
    *   **좌측 상단:** 현재 스테이지 이름 (예: `Stage 2 - Snowy Night`).
    *   **중앙 상단:** 스톱워치 (포맷: `00:00.00` - 분, 초, 소수점 두 자리). 분할선 위에 배경 패널을 깔아 숫자가 잘 보이게 함.
    *   **우측 상단:** 정답 진행도 UI (예: `( 2 / 5 )`).
*   **분할선:** 화면 중앙을 위에서 아래까지 가르는 얇은 세로선.
*   **일시정지 UI:** 키보드 `Esc` 입력 시 타이머가 정지(`Time.timeScale = 0`)되며, 화면 중앙에 반투명한 일시정지 팝업(계속하기, 메인 메뉴로 버튼) 출력.
*   **클리어 후 대기:** 마지막 정답을 찾은 뒤 다음 스테이지로 넘어가기까지 1.5초 동안은 클릭 판정과 일시정지를 받지 않음.
*   **시작 안내 UI (튜토리얼):** 화면 전체를 반투명 배경으로 덮고 중앙에 안내 창을 띄움. 이전/다음 버튼으로 페이지를 넘기고, 마지막 페이지의 시작하기 버튼으로 닫음. 안내 중에는 스톱워치·카메라·클릭·일시정지가 모두 멈추고, BGM은 일시정지 때처럼 볼륨을 낮춤.
*   **스톱워치 시작 시점:** 씬이 로딩된 직후의 첫 프레임은 기록에 넣지 않음(로딩 시간이 기록에 섞이지 않게). 안내가 있는 씬은 안내를 닫는 순간부터 잼.
*   **조명 연출:** 디오라마 모델링이 예쁘게 보이도록 화사한 Ambient Color와 그림자(Soft Shadows) 세팅에 집중.

### 4.3 결과 화면 (Result Scene)
*   **결과 팝업 UI:** 게임 클리어 시 부드럽게 화면 중앙에 사각형 형태의 결과표 패널이 나타남.
    *   **상세 기록:** 각 스테이지별 클리어 시간 리스트 텍스트 출력.
    *   **최종 기록:** "Total Time: 00:00.00"을 가장 크게 강조하여 출력.
    *   **버튼:** 패널 하단에 `Main Menu` 버튼 배치.

## 5. 상호작용 피드백

### 5.1 시각 피드백 (Visual Effect)
*   **정답 클릭 시:**
    *   선택된 두 물체의 머티리얼이 순간적으로 황금빛(또는 밝은 발광 Emission)으로 부드럽게 변하며 시각적 쾌감 제공.
    *   정답 오브젝트 위로 작은 반짝임 파티클(Particle) 재생.
*   **오답 클릭 시:**
    *   정답이 아닌 물체를 클릭하면 마우스 커서 위치에 작은 붉은색 X자 UI가 살짝 튀었다가 0.5초 안에 사라짐 (타격감만 주고 패널티는 없음).
    *   빈 곳(물체가 없는 곳) 클릭은 아무 반응도 하지 않음.
    *   오브젝트 흔들림은 보류 중 (코드는 주석으로 남겨 두어 다시 켤 수 있음).

### 5.2 청각 피드백 (Audio Effect)
*   **BGM:** 플레이어가 조급해하지 않고 관찰에 집중할 수 있도록, 씬 전체를 아우르는 잔잔하고 편안한(Lofi 또는 어쿠스틱) BGM 루프 재생. 씬이 바뀌어도 끊기지 않고 이어지며, 일시정지 중에는 볼륨을 30%로 부드럽게 낮춤.
*   **SFX:**
    *   정답 클릭: 맑고 청량한 실로폰/종소리 핑(Ping) 사운드.
    *   오답 클릭: 둔탁하지만 불쾌하지 않은 '뾱' 또는 '삐빅' 소리.
    *   버튼 클릭: 깔끔한 UI 클릭 사운드.
